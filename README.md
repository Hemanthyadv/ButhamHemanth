# Hemanth Butham — Personal Portfolio

A cinematic, recruiter-friendly personal portfolio for **Hemanth Butham**, focused on AI, data engineering and software engineering.

## Design direction

The experience takes inspiration from editorial/cinematic developer portfolios: narrative scrolling, strong typography, motion, project storytelling and a fast recruiter path. It is an original design built around Hemanth's engineering work rather than a copy of another portfolio.

## Featured work

- **Industrial Intelligence Platform** — Kafka, Spark Structured Streaming, Delta Lake, MLflow, anomaly detection, forecasting, FastAPI and observability.
- **GNN Fraud Detection** — heterogeneous graph neural networks with GAT, GraphSAGE and explainability.
- **Transformer Forecasting** — time-series forecasting experiments with transformer-based modeling.
- **Causal Inference Platform** — causal analysis and treatment-effect workflows.

## Run locally

No build step is required.

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy

The repository includes `.github/workflows/deploy-pages.yml` for GitHub Pages. Pushes to `main` trigger deployment.
